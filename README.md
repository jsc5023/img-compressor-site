📸 무료 이미지 압축기 (Free Image Compressor)

JPG/PNG 이미지 용량을 빠르게 줄이면서 화질은 최대한 유지하는 무료 온라인 이미지 압축 도구입니다.
블로그, 스마트스토어, 포트폴리오, SNS 업로드 시 용량 제한이 있을 때 유용하게 사용할 수 있습니다.

🔗 실제 서비스 바로가기:
https://img-compressor-site.vercel.app/

✨ 주요 기능 (Features)
✔ 1. 이미지 용량 압축

JPG / PNG 지원

JPEG 품질(0.3 ~ 0.95) 조절

이미지 최대 가로/세로 크기 설정

PNG → JPG 자동 변환 옵션

✔ 2. 드래그 앤 드롭 업로드

파일 선택 버튼 지원

업로드 영역에 이미지 드래그 앤 드롭 가능

✔ 3. 멀티 이미지 일괄 처리

여러 이미지 동시 업로드

한 번에 압축 처리 후 결과 제공

✔ 4. 고화질 유지 알고리즘

Canvas API 기반 이미지 압축

용량 대비 화질 최적화

브라우저 자체 처리 → 서버 비용 없음

✔ 5. 결과 다운로드 기능

압축된 이미지 미리보기

JPG/PNG 변환 결과 다운로드

개별 이미지 저장 가능
